# User Roles

RoosterViewCall defines six user roles.

---

## Administrator

Responsible for system configuration.

Responsibilities:

- Manage users
- Configure business
- Configure printers
- Configure displays
- Configure ticket numbering
- View reports

---

## Cashier

Responsible for customer service at the point of sale.

Responsibilities:

- Create orders
- Print tickets
- Receive payments
- Update order status

---

## Kitchen

Responsible for food preparation.

Responsibilities:

- View pending orders
- Start preparation
- Complete preparation
- Notify finished orders

---

## Public Display

Displays information to customers. Not an interactive role — it is a passive, screen-based presence.

Responsibilities:

- Show completed orders
- Show orders in preparation
- Play promotional content
- Play notification sounds

---

## Supervisor

Responsible for monitoring the operation.

Responsibilities:

- View dashboards
- Analyze metrics
- Monitor kitchen performance
- Monitor waiting times

---

## Customer

Interacts only through the public interface. Has no account and no login.

Responsibilities:

- Receive ticket
- Wait for order
- Pick up food
