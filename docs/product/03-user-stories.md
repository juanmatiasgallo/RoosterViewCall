# User Stories

User stories are organized by role, following the format:

> As a [role], I want to [action], so that [benefit].

---

## Administrator

- As an Administrator, I want to create and manage staff accounts, so that only authorized personnel can access the system.
- As an Administrator, I want to configure the business profile, so that tickets and displays reflect my brand identity.
- As an Administrator, I want to configure printers and displays, so that hardware works correctly at each location.
- As an Administrator, I want to configure ticket numbering, so that order sequences match my business needs.
- As an Administrator, I want to view operational reports, so that I can evaluate the business performance over time.

---

## Cashier

- As a Cashier, I want to create a new order quickly, so that customers are served without delay.
- As a Cashier, I want to print a ticket for the customer, so that they have a reference to track their order.
- As a Cashier, I want to receive payment as part of the order flow, so that the transaction is completed in one step.
- As a Cashier, I want to update an order's status, so that the kitchen and customer stay in sync.

---

## Kitchen

- As Kitchen staff, I want to see all pending orders in real time, so that I know what to prepare next.
- As Kitchen staff, I want to mark an order as "in preparation," so that other roles know it is being worked on.
- As Kitchen staff, I want to mark an order as "complete," so that the customer is notified it is ready.
- As Kitchen staff, I want orders to be clearly prioritized, so that I can manage preparation order efficiently.

---

## Public Display

- As the Public Display, I want to show orders that are ready for pickup, so that customers know when to approach the counter.
- As the Public Display, I want to show orders currently in preparation, so that customers have visibility into wait times.
- As the Public Display, I want to highlight newly completed orders, so that they are easy to notice.
- As the Public Display, I want to play a notification sound when an order is completed, so that customers are alerted even if not looking at the screen.
- As the Public Display, I want to show promotional content alongside order status, so that the screen also serves a marketing purpose.

---

## Supervisor

- As a Supervisor, I want to view a real-time dashboard, so that I can monitor the operation at a glance.
- As a Supervisor, I want to see average waiting times, so that I can identify service bottlenecks.
- As a Supervisor, I want to see kitchen performance metrics, so that I can evaluate preparation efficiency.
- As a Supervisor, I want to review historical statistics, so that I can make informed operational decisions.

---

## Customer

- As a Customer, I want to receive a ticket after placing an order, so that I have a reference for my order.
- As a Customer, I want to see my order's status on the public display, so that I know when it will be ready.
- As a Customer, I want to be clearly notified when my order is ready, so that I can pick it up promptly.
